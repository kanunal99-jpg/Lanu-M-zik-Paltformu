# LANU Music — Professional Release Gate

The application is released only when implementation and verification agree.

Required: Unit/Robolectric tests, APK build, generated SHA-256, independent artifact verification, and passing post-merge Main CI.

Product integrity requirements: no fabricated catalog or engagement data; local/verified audio only; user-scoped library persistence; real playback history; offline file reconciliation; Media3/MediaSession as playback authority.
